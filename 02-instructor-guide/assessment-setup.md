# پیکربندی آزمون‌ها و تکالیف (`infoAssessment.json`)

آزمون‌ها و تکالیف در مسیر `courseInstances/<term>/assessments/<assessment_name>/` تعریف می‌شوند و تمامی تنظیمات نمره‌دهی، استخرهای سوالات و قوانین دسترسی در فایل `infoAssessment.json` قرار می‌گیرند.

---

## ۱. پیش‌نیاز حیاتی: مجموعه‌های ارزیابی (`assessmentSets`)

در فایل `infoAssessment.json` فیلد `"set"` مشخص‌کننده دسته‌بندی ارزیابی است (مانند تکلیف، کوییز یا آزمون پایان‌ترم). **این نام باید حتماً از قبل در فایل `infoCourse.json` تعریف شده باشد:**

```json
// در فایل infoCourse.json
{
  "assessmentSets": [
    { "name": "Homework", "abbreviation": "HW", "heading": "تکالیف کلاسی", "color": "blue1" },
    { "name": "Quiz", "abbreviation": "Q", "heading": "کوییزهای هفتگی", "color": "purple1" },
    { "name": "Exam", "abbreviation": "E", "heading": "آزمون‌های میان‌ترم و پایان‌ترم", "color": "red1" }
  ]
}
```

---

## ۲. کالبدشکافی ساختار فایل `infoAssessment.json`

یک نمونه کامل از آزمون دانشگاهی با زمان‌سنج و دسترسی مشخص:

```json
{
  "uuid": "8b23c5e8-42f1-482a-bc93-a442812903de",
  "type": "Exam",
  "title": "آزمون میان‌ترم برنامه‌نویسی پایتون",
  "set": "Exam",
  "number": "1",
  "text": "مدت زمان آزمون ۹۰ دقیقه است. استفاده از مراجع و اینترنت مجاز نمی‌باشد.",
  "timeLimitMin": 90,
  "allowRealTimeGrading": true,
  "zones": [ ... ],
  "allowAccess": [ ... ]
}
```

## ۳. بخش‌ها (Zones) و استخرهای سوالات (Question Pools)

برای جلوگیری از تقلب، آزمون‌ها به چندین **بخش (Zone)** تقسیم می‌شوند و در هر بخش، سامانه سوالاتی را به صورت تصادفی از میان گزینه‌های هم‌تراز (Alternatives) برای هر دانشجو انتخاب می‌کند.

### ساختار استاندارد استخر سوالات:
```json
"zones": [
  {
    "title": "بخش ۱: مبانی و مفاهیم الگوریتم",
    "comment": "یک سوال تصادفی از میان ۳ سوال این بخش انتخاب می‌شود",
    "maxPoints": 20,
    "questions": [
      {
        "numberChoose": 1,
        "autoPoints": 20,
        "alternatives": [
          { "id": "algorithm_complexity_variant_a" },
          { "id": "algorithm_complexity_variant_b" },
          { "id": "algorithm_complexity_variant_c" }
        ]
      }
    ]
  },
  {
    "title": "بخش ۲: پیاده‌سازی و کدنویسی",
    "bestQuestions": 2,
    "questions": [
      { "id": "python_binary_search", "autoPoints": 30 },
      { "id": "python_quick_sort", "autoPoints": 30 },
      { "id": "python_merge_sort", "autoPoints": 30 }
    ]
  }
]
```

### ویژگی‌های پیشرفته بخش‌ها (Zones):
- `numberChoose`: تعداد سوالاتی که باید به صورت تصادفی از این استخر به دانشجو اختصاص داده شود.
- `maxPoints`: حداکثر سقف امتیازی که دانشجو می‌تواند از این بخش کسب کند.
- `bestQuestions`: محاسبه نمره نهایی بخش تنها از $n$ سوالی که دانشجو بالاترین امتیاز را در آن‌ها آورده است.
- `lockpoint: true`: پس از این که دانشجو پاسخ‌های این بخش را ارسال کرد و به بخش بعدی رفت، امکان ویرایش یا بازگشت به این بخش قفل می‌شود.

## ۴. قوانین دسترسی و سیاست‌های زمانی (`allowAccess`)

سامانه قوانین دسترسی را **به ترتیب از بالا به پایین** ارزیابی می‌کند؛ اولین قانونی که شرایط آن صادق باشد، تعیین‌کننده دسترسی دانشجو خواهد بود:

```json
"allowAccess": [
  {
    "mode": "Public",
    "uids": ["special_student@university.ac.ir"],
    "comment": "استثنا: وقت اضافه ۵۰٪ برای دانشجوی دارای گواهی پزشکی",
    "startDate": "2026-11-20T08:00:00",
    "endDate": "2026-11-20T11:00:00",
    "timeLimitMin": 135
  },
  {
    "mode": "Public",
    "comment": "بازه زمان اصلی آزمون با رمز عبور و محدودیت IP سالن امتحانات",
    "startDate": "2026-11-20T08:00:00",
    "endDate": "2026-11-20T10:00:00",
    "password": "Exam2026Secure!",
    "ipRanges": ["192.168.10.0/24", "172.16.0.0/16"],
    "credit": 100
  },
  {
    "mode": "Public",
    "comment": "فرصت تاخیر با کسر ۲۰ درصد از سقف نمره",
    "startDate": "2026-11-20T10:00:01",
    "endDate": "2026-11-20T12:00:00",
    "credit": 80
  },
  {
    "mode": "Public",
    "comment": "دسترسی آزاد فقط برای مرور و تمرین بدون تاثیر در نمره نهایی",
    "startDate": "2026-11-20T12:00:01",
    "active": true,
    "credit": 0
  }
]
```

### نکات کلیدی قوانین دسترسی:
1. **قانون اولویت ترتیبی:** همیشه استثناهای اشخاص (`uids`) یا گروه‌های خاص باید **بالاتر** از قوانین عمومی قرار گیرند.
2. **سیاست `credit` در تاخیر:** اگر دانشجو در بازه ۱۰۰٪ نمره کامل بگیرد، ورود به بازه ۸۰٪ نمره او را کسر نمی‌کند. این فیلد سقف نمرات تلاش‌های جدید است.
3. **ارزش تمرینی (`credit: 0`):** دانشجو می‌تواند بعد از پایان امتحان، سوالات را حل کند و بازخورد فوری دریافت کند، بدون آن که نمره نهایی کارنامه تغییر کند.
4. **محدودسازی به IP (`ipRanges`):** برای آزمون‌های رسمی حضوری، اجازه باز شدن آزمون فقط از طریق سیستم‌های درون دانشگاه امکان‌پذیر است.
