# میزکارهای ابری تعاملی (Workspaces)

قابلیت میزکار ابری (Workspace) به دانشجو اجازه می‌دهد مستقیماً درون مرورگر به یک محیط توسعه کامل (مانند **VS Code** یا **JupyterLab** یا ترمینال لینوکس) دسترسی داشته باشد، بدون اینکه نیاز به نصب هیچ نرم‌افزاری روی کامپیوتر شخصی خود داشته باشد.

---

## ۱. چه زمانی از Workspace استفاده می‌کنیم؟

1. **پروژه‌های چند فایلی**: زمانی که دانشجو باید چندین فایل کلاسی، هدر، ماژول و فایل کانفیگ بنویسد.
2. **دروس علم داده و هوش مصنوعی**: کار با نوت‌بوک‌های Jupyter و کتابخانه‌های NumPy، Pandas و Matplotlib.
3. **دروس سیستم‌های عامل و شبکه**: دسترسی به محیط ترمینال لینوکس، ابزارهای Bash، کامپایلرهای GCC، GDB و Make.

---

## ۲. نحوه فعال‌سازی Workspace در سوال

در فایل `question.html`:

```html
<pl-question-panel>
  <p>
    پروژه پیاده‌سازی سیستم مدیریت پایگاه داده را در محیط VS Code زیر توسعه دهید.
    پس از اتمام، دکمه ذخیره و ارسال پاسخ را در پایین همین صفحه فشار دهید.
  </p>
</pl-question-panel>

<pl-workspace></pl-workspace>
<pl-submission-panel></pl-submission-panel>
```

و در فایل `info.json`:

```json
{
  "uuid": "c3d4e5f6-a7b8-9012-cdef-0123456789ab",
  "title": "پروژه سیستم عامل: توسعه فایل سیستم",
  "topic": "سیستم‌های عامل",
  "type": "v3",
  "workspaceOptions": {
    "image": "prairielearn/workspace-vscode",
    "port": 8080,
    "home": "/home/coder"
  }
}
```

---

## ۳. ویژگی‌های محیط Workspace برای دانشجو
- ذخیره خودکار فایل‌ها در فضای ابری اختصاصی هر دانشجو.
- امکان تست و اجرای تعاملی کد در ترمینال داخلی VS Code.
- عدم نیاز به تنظیم Environment Variables، کامپایلر یا پایتون روی لپ‌تاپ دانشجو.
